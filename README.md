# Pulse for Windows

Pulse is a fullscreen now-playing companion and audio visualizer for Windows. It follows the current Windows media session and builds its ambient background from the artwork palette.

## Download

Download **Pulse-v0.3.18.zip** from the [latest release](https://github.com/lukasmacko2008-web/Pulse/releases/latest), extract the `Pulse` folder, and run `Pulse.exe`.

## Highlights

- Fullscreen artwork view with playback controls
- Animated ambient colors drawn from the artwork palette
- Optional system-audio spectrum visualizer and subtle bass response
- Small floating media widget and multi-monitor fullscreen
- Optional Chrome extension for higher-resolution Spotify Web Player artwork

## Requirements

- Windows x64
- Windows 10 version 1809 or newer
- .NET Framework 4.8

The Spotify extension is optional and pairs locally with Pulse. Each installation creates its own settings and pairing key; personal keys and settings are not included in downloads.
